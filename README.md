# LuxeRank

高端奢侈品生活方式产品评测联盟营销网站 v2.1

## 技术栈

- **框架**: Astro（静态站点生成）
- **样式**: Tailwind CSS + CSS 自定义属性
- **图标**: Lucide React
- **字体**: Google Fonts — Playfair Display（标题）+ Inter（正文）
- **动画**: AOS（Animate on Scroll）

## 快速开始

\\\ash
npm install
npm run dev      # 启动开发服务器
npm run build    # 构建生产版本
npm run preview  # 预览构建结果
\\\

## 部署

兼容 Cloudflare Pages / Vercel，直接推送 \dist/\ 目录即可。

## 网站信息

- **域名**: luxerrank.com
- **风格**: 奢华金色主题，深色页脚，玻璃态导航栏
